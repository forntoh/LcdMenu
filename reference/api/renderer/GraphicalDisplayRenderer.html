GraphicalDisplayRenderer

class GraphicalDisplayRenderer : public MenuRenderer, public FrameLifecycleRenderer, public GraphicalIndicatorRenderer, public GraphicalValueSelectionRenderer, public GraphicalRendererContext
#include <GraphicalDisplayRenderer.h>

Renderer for pixel-addressable displays (for example U8g2-backed).
